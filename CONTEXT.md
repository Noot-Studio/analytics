# Domain Glossary

Canonical vocabulary for s&box Analytics. Use these terms in issue titles, test names, and proposals — don't drift to synonyms.

## Control plane (Postgres / Prisma)

| Term             | Definition                                                                                                                                                                                                                                                      |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Organization** | Top-level tenant. Owns projects, members, invitations, billing.                                                                                                                                                                                                 |
| **Member**       | A user's membership in an organization, with a role: Owner, Admin, or Viewer.                                                                                                                                                                                   |
| **Invitation**   | A pending offer to join an organization with a given role.                                                                                                                                                                                                      |
| **Project**      | A game (or one environment of a game) sending events. Belongs to one organization; identified by `slug` unique per org. Has an environment: Development, Staging, or Production.                                                                                |
| **API key**      | A key pair issued to a project. The **publishable key** (`pk_…`) is stored in plaintext and sent by game clients in the `X-Api-Key` header. The **secret key** (`sk_…`) is shown once and stored only as a hash. Keys are revoked, never deleted (`revokedAt`). |
| **Dashboard**    | A customizable grid of cards. Scoped by `DashboardScope`: `OrgOverview`, `ProjectOverview`, or `CustomPage` (reserved, unused).                                                                                                                                 |
| **Card**         | One widget on a dashboard, instantiating a card definition at a `CardSize` (Third, Half, TwoThirds, Full).                                                                                                                                                      |

## Analytics plane (ClickHouse)

| Term                   | Definition                                                                                                                                                                  |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Event**              | One row in `analytics.events`: `event_type`, `timestamp`, `session_id`, `player_id`, `properties`, optional `scene` + `position`. Ingested via `POST /v1/events` (batched). |
| **Core events**        | `session_start`, `session_end`, `player_death`, `level_complete`, `custom_event`.                                                                                           |
| **Performance events** | `fps_sample`, `crash`, `load_complete`.                                                                                                                                     |
| **Session**            | The span between a `session_start` and its `session_end`, keyed by `session_id` (UUID generated by the client).                                                             |
| **Player**             | An anonymous participant, keyed by `player_id` — an anonymized hash. Never PII; never linked to a real identity.                                                            |
| **Spatial event**      | An event carrying `scene` + `position`, aggregated into **voxels** for in-world heatmaps.                                                                                   |
| **Retention cohort**   | Players grouped by first-seen date (`analytics.player_first_seen`), measured at Day-1/7/30.                                                                                 |
| **Funnel**             | An ordered sequence of event types players are expected to progress through.                                                                                                |
