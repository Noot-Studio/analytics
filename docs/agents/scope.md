# Project Scope

## In Scope

- Hono + oRPC + TanStack Router monorepo scaffold
- Authentication service (Better Auth + Prisma)
- User, organization, and project management
- API key generation (publishable + secret pairs)
- Event ingestion API with validation
- Kafka/Redpanda event streaming pipeline
- ClickHouse schema and aggregation pipelines
- C# SDK for s&box integration (NuGet)
- React dashboard with real-time metrics and Recharts visualizations
- Public documentation (Fumadocs)
- Polar.sh billing integration

## Out of Scope (Future)

- Support for non-s&box game engines (Unity, Godot)
- Managed cloud migration (OVH → AWS/GCP/Azure)
- Mobile or desktop app dashboards
- Real-time multiplayer networking features
