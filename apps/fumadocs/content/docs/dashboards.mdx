The **Overview** page — both the Organization-wide one and each [Project](/docs/projects)'s — is a customizable dashboard: a grid of cards you can add, remove, resize, and reorder. The layout is saved per Organization (org overview) or per Project (project overview) and is shared by everyone in the Organization.

## Customizing a dashboard

1. Open an overview page and choose **Customize**.
2. **Add card** opens a drawer listing the built-in cards and your saved custom statistics. Drag cards to reorder them, use a card's size menu to resize it, or remove it.
3. Changes save automatically while you edit. Choose **Done** when you're finished.

Cards come in four widths — third, half, two-thirds, and full — and a dashboard holds up to **30 cards**. The page's global time-range picker applies to every card.

## Built-in cards

| Card               | Shows                                                                              |
| ------------------ | ---------------------------------------------------------------------------------- |
| **Total events**   | Event count for the selected range, with the change vs the preceding period.       |
| **Unique players** | Distinct players for the selected range, with the change vs the preceding period.  |
| **Sessions**       | Distinct sessions for the selected range, with the change vs the preceding period. |
| **Events per day** | Time-series chart of daily event volume.                                           |
| **Events by type** | Breakdown list of the most common event types.                                     |

On the **Organization overview**, a built-in card aggregates across every Project by default, or can be pinned to a single Project when you add it. On a **Project overview**, cards always show that Project's data.

## Custom statistic cards

A custom statistic card runs a query you define and renders the result as a single **metric** or a **timeseries** chart:

- **Aggregation** — `count`, `sum`, `avg`, `min`, `max`, `unique_players`, or `unique_sessions`. The numeric aggregations read a `properties` key you name (for example, `avg` over `fps`).
- **Event type** — restrict the query to a single event type, or span all events.
- **Filters** — up to 10 conditions, combined with `and`/`or`.
- **Granularity** — `hour`, `day`, `week`, or `month` buckets for timeseries cards; metric cards collapse the whole range into one number.

<Callout type="info">
  Custom statistics query a single Project. On the Organization overview you
  pick which Project a custom card reads from when adding it.
</Callout>

Saving a custom statistic adds it to your card **library**: it appears in the add-card drawer so you can reuse it on other dashboards, and can be deleted from there when no longer needed.
