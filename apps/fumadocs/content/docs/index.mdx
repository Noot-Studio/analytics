s&box Analytics is a real-time analytics platform purpose-built for [s&box](https://sbox.game) game developers. It gives you player-behavior insights, session tracking, and performance monitoring without the bloat of general-purpose marketing analytics.

## How it fits together

You organize your work into three layers. Each one nests inside the one above it:

<Cards>
  <Card title="Organizations" href="/docs/organizations">
    The top-level workspace that owns your games, billing, and teammates.
  </Card>
  <Card title="Projects" href="/docs/projects">
    A single game (or one environment of it) that events are scoped to.
  </Card>
  <Card title="API Keys" href="/docs/api-keys">
    Per-project credentials your game uses to send events.
  </Card>
</Cards>

```text
Organization
└── Project (Development / Staging / Production)
    └── API Key (pk_… / sk_…)
        └── Events  →  POST /v1/events
```

## Getting started

1. **Create an Organization** — your workspace. See [Organizations](/docs/organizations).
2. **Create a Project** for your game. See [Projects](/docs/projects).
3. **Generate an API Key** for that project. See [API Keys](/docs/api-keys).
4. **Send events** from your game to the Ingestion API. See [API Usage](/docs/api).

## Send your first event

Once you have a publishable key, ingestion is a single HTTP request:

```bash
curl -X POST https://ingest.sbox-analytics.com/v1/events \
  -H "x-api-key: pk_your_publishable_key" \
  -H "Content-Type: application/json" \
  -d '{
    "events": [
      { "type": "level_completed", "session_id": "sess_123", "player_id": "76561198000000000" }
    ]
  }'
```

Head to [API Usage](/docs/api) for the full reference, authentication details, and interactive requests you can run from the page.
