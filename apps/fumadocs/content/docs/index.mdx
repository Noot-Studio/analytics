s&box Analytics is real-time game analytics built for [s&box](https://sbox.game) developers — player behavior, sessions, and performance, without the marketing bloat.

This guide takes you from nothing to a live chart in under ten minutes. You'll create a project, grab a key, drop one component into your game, and watch the events land.

<Callout type="info">
  You need a running analytics platform to send events to. Use the hosted cloud
  platform, or [run it locally](/docs/local-setup) for development. The steps
  below are identical either way — only the ingest URL changes.
</Callout>

## 1. Create a project and key

Events are scoped to a [Project](/docs/application/workspace#projects), and your game authenticates with that project's **publishable key** (`pk_…`).

1. In the dashboard, create (or pick) an [Organization](/docs/application/workspace).
2. Create a **Project** for your game.
3. Open the project, choose **Create API key**, and copy the **publishable key** (`pk_…`).

Use the `pk_` key in your game — never the secret `sk_` key. See [API keys](/docs/application/api-keys) for the difference.

## 2. Install the SDK

1. Browse to **[sbox.game/noot](https://sbox.game/noot)** and open the **Analytics** (`noot.analytics`) library.
2. Add it to your project under **Project Settings → Packages** in the s&box editor.

## 3. Drop in the component

The zero-code path needs no scripting:

1. In the hierarchy panel's **Create** menu (the **+** button, or right-click), choose **Analytics Helper**.
2. Select it and paste your `pk_…` key into the **ApiKey** field.
3. Press **play**.

That's it. `session_start`, `scene_loaded`, and connection events now flow automatically.

<Callout type="info">
  Running the platform locally? Set the component's **IngestUrl** field to your
  local ingest host (e.g. `http://localhost:8080`) instead of the cloud default.
</Callout>

## 4. See your first chart

Buffered events flush every 10 seconds, so give it a moment. Then open your project's **Overview** in the dashboard — the **Total events** and **Events per day** widgets light up as data arrives.

If nothing shows after a minute, check that the key is a `pk_…` key for the right project and that the ingest URL matches your platform.

## Next: track your own events

The component gets you default events for free. To record what's unique to your game — kills, purchases, level completions — head to the [SDK reference](/docs/sdk). It's the primary way to send events and the most important section of these docs.
