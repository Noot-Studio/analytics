# `apps/fumadocs` — Public Documentation Site

The public docs for the s&box Analytics platform: API reference, SDK guide, and tutorials. Built with [Fumadocs](https://fumadocs.dev) on TanStack Start + Vite, content authored as MDX.

## Stack

- **Fumadocs UI + Core + MDX** — docs framework with built-in search (Orama).
- **TanStack Start + Router** — file-based routing, can serve statically or SSR.
- **Vite** dev server on port 4000 (`bun run dev` from this folder).
- **Biome** — this app uses its own Biome config (`biome.json`) rather than Ultracite/Oxlint.

## Layout

```
content/            # MDX docs — the source of truth for what readers see
src/
  routes/           # TanStack Router pages that render Fumadocs
  components/       # Doc-specific React components (callouts, code blocks, etc.)
  lib/              # MDX/source helpers
  utils/            # Misc
source.config.ts    # Fumadocs MDX source configuration
.source/            # Generated by fumadocs-mdx — do not edit
```

## Run

```bash
cd apps/fumadocs && bun run dev          # dev server, port 4000
bun run build && bun run start           # static build + serve
```

`postinstall` runs `fumadocs-mdx` to generate `.source/`. If imports from `.source` break, re-run `bun install` or `bunx fumadocs-mdx`.

## Conventions

- Author docs in `content/` as `.mdx`. Slugs map to URLs via Fumadocs conventions.
- Keep the API reference in sync with the oRPC OpenAPI document exposed at `apps/server`'s `/api-reference` — when a procedure changes, update the corresponding MDX page.
- Doc-specific components stay here. Anything generally useful belongs in `packages/ui`.
- Lint/format with `bun run lint` / `bun run format` (Biome) — root `bun run check` does **not** cover this app.
